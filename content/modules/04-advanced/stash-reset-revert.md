# stash, reset и revert

Три инструмента для ситуаций «надо срочно переключиться» и «я сделал лишний коммит».

## git stash: спрятать недоделанное

Ситуация: ты правишь файл, приходит срочная задача в другой ветке, а коммитить половину работы не хочется.

```bash
git stash             # спрятать все изменения, рабочая папка снова чистая
git switch urgent-fix # спокойно переключиться
# ... сделал срочное ...
git switch feature
git stash pop         # вернуть изменения обратно
```

Полезное:

```bash
git stash list        # что лежит в «кладовке»
git stash -m "черновик формы"   # с подписью
git stash apply       # вернуть, но оставить в списке
git stash drop        # выбросить верхнюю запись
```

:::note stash локальный
Stash не уходит в коммиты и не отправляется на сервер. Это личный карман, а не способ поделиться работой.
:::

## git reset: отменить коммит

`reset` двигает указатель ветки назад. Важно, **что происходит с изменениями**:

| Вариант | Коммит | Staging | Файлы |
|---|---|---|---|
| `--soft` | отменён | изменения остаются | изменения остаются |
| `--mixed` (по умолчанию) | отменён | очищается | изменения остаются |
| `--hard` | отменён | очищается | **изменения удалены** |

```bash
git reset --soft HEAD~1     # «ой, забыл файл» — вернуть коммит в staging
git reset HEAD~1            # переписать коммит заново
git reset --hard HEAD~1     # выбросить коммит вместе с правками (осторожно!)
```

:::danger --hard не спрашивает
`--hard` стирает незакоммиченные изменения без подтверждения. Если случайно — `git reflog` покажет, где ты был, и поможет вернуться (но только для закоммиченного).
:::

## git revert: отменить, не ломая историю

Если коммит уже улетел в общую ветку, `reset` перепишет историю у всех — это плохо. Вместо этого `revert` создаёт **новый коммит**, который отменяет изменения старого.

```bash
git revert HEAD             # отменить последний коммит
git revert a1b2c3d          # отменить конкретный
```

История остаётся линейной, коллегам ничего переделывать не нужно.

## Что выбрать

- Работаешь один, коммит не отправлен → `reset`.
- Коммит уже в общей ветке → `revert`.
- Надо срочно переключиться, коммитить рано → `stash`.
- Испугался, что что-то потерял → `git reflog`.

## Мини-практика

В терминале ниже репозиторий с одним коммитом и незакоммиченной правкой.

1. `git status` — увидеть изменение.
2. `git stash` — рабочая папка стала чистой, файл вернулся к версии из коммита.
3. `git stash list` — запись на месте.
4. `git stash pop` — изменение вернулось.
5. `git add .` и `git commit -m "wip: draft"` — теперь есть лишний коммит.
6. `git reset --soft HEAD~1` — отменить его, оставив изменения в staging.
7. `git reset --hard HEAD` — вернуть всё как было.
