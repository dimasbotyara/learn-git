# Что такое Git и при чём тут GitHub

Представь, что ты пишешь текстовый файл и хочешь сохранять не только «финальную» версию, а **всю историю**: что менялось, когда и зачем. Git — это программа, которая делает именно это. Она живёт на твоём компьютере, работает без интернета и хранит историю в скрытой папке `.git` внутри проекта.

:::note Простая аналогия
Git — это **машина времени для папки с файлами**. GitHub — это **облачный сейф**, куда эту машину времени можно положить, чтобы её увидели другие.
:::

## Git и GitHub — не одно и то же

Это самая частая путаница у новичков, поэтому запомним раз и навсегда:

| | Git | GitHub |
|---|---|---|
| Что это | программа контроля версий | сайт-хостинг для Git-репозиториев |
| Где живёт | на твоём компьютере | в интернете |
| Нужен интернет | нет | да |
| Кто сделал | Линус Торвальдс, 2005 | компания GitHub, 2008 |

GitHub — не единственный хостинг. Есть GitLab, Bitbucket, Codeberg. Git при этом остаётся тем же самым.

:::tip Как не путаться
Если ты в терминале набираешь команду — это почти всегда **Git**. Если ты открываешь страницу в браузере и нажимаешь «Create repository» — это **GitHub**.
:::

## Что Git умеет

- **Хранит историю.** Каждое сохранение — отдельный снимок (коммит), к которому можно вернуться.
- **Работает локально.** Коммиты не требуют интернета: он нужен только для отправки на сервер.
- **Позволяет ветвиться.** Ты можешь делать эксперимент в отдельной ветке, а основную не трогать.
- **Помогает работать вместе.** Несколько человек могут менять один проект, а Git аккуратно сведёт изменения.

## Как выглядит работа

Цикл, который ты будешь повторять каждый день:

```bash
git status          # 1. посмотреть, что изменилось
git add .           # 2. выбрать изменения
git commit -m "..." # 3. сохранить снимок
git push            # 4. отправить на GitHub
```

Пока это выглядит как заклинания — это нормально. Дальше каждый шаг разберём отдельно и потрогаем руками.

## Проверь себя

Ответь себе на два вопроса, прежде чем идти дальше:

1. Можно ли сделать коммит без интернета? *(Да — Git работает локально.)*
2. Если удалить аккаунт на GitHub, исчезнет ли Git на компьютере? *(Нет, это разные вещи.)*
